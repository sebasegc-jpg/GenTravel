## Sobre el proyecto

**GenTravel** es una aplicación web para planificar viajes, hecha con HTML, CSS y JavaScript sin frameworks. Usa una Google Sheet como base de datos, conectada mediante un Google Apps Script (`apps-script/Code.gs`).

Incluye:

- **Itinerario:** grilla horaria por semanas con eventos, alojamientos y medios de transporte.
- **Recomendaciones:** lugares para visitar que se pueden pasar al itinerario.
- **Mapa:** mapa interactivo (Leaflet) con pines, trayectos y una cronología del viaje.
- **Gastos:** registro de gastos entre viajeros con conversión entre yenes, dólares y pesos argentinos.
- **Temas de color** que se pueden elegir desde la propia app.
